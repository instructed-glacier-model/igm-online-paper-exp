# Shared scientific helpers

Helpers used by the study scripts:

| Module | Purpose |
|---|---|
| `igm_online/` | IGM adapters, reference convergence, metrics and checkpoints |
| `snapshots.py` | Anchor checkpoints and correction branches |
| `exports.py`, `tables.py` | Numerical summaries and LaTeX tables |
| `configs/` | Architecture specifications and normalization values |

IGM: https://github.com/instructed-glacier-model/igm (GPL-3.0). DahuNet experiment code: Thomas Gregov and collaborators.
